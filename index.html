Prompting & LLM Engineering

Interactive knowledge hub compiled from the complete course modules.

01. Introduction

Covers fundamental prompting mechanics: system vs user directives, role definition, zero-shot and few-shot formatting, and output framing.

02. Understanding LLMs

Explores transformer-based generative architecture, probability distributions, next-token prediction, token limits, and hallucination reduction strategies.

03. Chat Models

Examines conversational state handling, multi-turn contexts, role management (system, user, assistant), and maintaining conversational continuity.

04. Designing LLM Applications

Techniques for production readiness: pipeline chaining, structured output enforcement (JSON schema mode), and input sanitization.

05. Prompts, Context and RAG

Deep-dive into Retrieval-Augmented Generation workflows: embedding spaces, vector database querying, dynamic context injection, and semantic indexing.

06. Laboratory Workbook

Practical laboratory exercises, test benches, and repeatable prompt evaluation frameworks.
